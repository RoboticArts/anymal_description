# anymal_description

This repository includes STL meshes and URDF files originating from the [ANYmal D robot description](https://github.com/ANYbotics/anymal_d_simple_description) repository, released under the BSD 3-Clause License.

The URDF files have been reorganized and adapted to fit a different system architecture. Original copyright notices are preserved. 
New system architecture and integration work are original contributions. 

This repository is part of [quadruped_ros2](https://github.com/RoboticArts/quadruped_ros2) project.
